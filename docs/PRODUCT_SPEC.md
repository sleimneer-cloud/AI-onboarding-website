# IX Value Loop

## 인터엑스 핵심가치 연계형 신규 입사자 온보딩 포털 기획안

> 문서 역할: 제품의 배경, 목표, 사용자 경험 및 MVP 검증 의도를 설명하는 기획
> 기준 문서다. 구현 세부사항은 `DECISIONS.md`, `DATA_MODEL.md`,
> `STATE_TRANSITIONS.md`, `LLM_CONTRACT.md`, `API_CONTRACT.md`를 따른다.

## 1. 기획 배경

신규 입사자는 입사 직후 회사의 핵심가치를 교육받지만, 가치의 정의를 읽고 암기하는 것만으로는 실제 업무에서 이를 실천하기 어렵다.

특히 동일한 핵심가치라도 직무와 업무 상황에 따라 구체적인 행동 방식은 달라진다. 예를 들어 ‘강박적 호기심’은 AX 직무에서는 사용자 인터뷰와 업무 프로세스 분석으로, 개발 직무에서는 기술 검증과 장애 원인 탐색으로 나타날 수 있다.

또한 신규 입사자는 별도의 온보딩 활동보다 팀장이 배정한 실제 업무를 중심으로 일한다. 따라서 온보딩을 별도의 교육 프로그램으로 운영하면 업무와 분리되거나 추가적인 보고 업무로 인식될 가능성이 높다.

IX Value Loop는 신규 입사자가 실제 업무를 수행하는 과정에서 인터엑스의 핵심가치를 행동으로 실천하고, 그 근거와 피드백을 축적하도록 돕는 업무 연계형 온보딩 시스템이다.

## 2. 핵심 문제

기존의 핵심가치 온보딩에는 다음과 같은 한계가 있다.

- 핵심가치가 추상적인 문장으로 전달되어 실제 업무 행동으로 연결되기 어렵다.
- 직무와 업무 상황이 다른데도 모든 입사자에게 동일한 교육이 제공된다.
- 교육과 실제 업무가 분리되어 온보딩 활동이 추가 과제로 느껴진다.
- 입사자가 가치를 이해했는지는 확인할 수 있지만, 실제로 적용했는지는 판단하기 어렵다.
- 온보딩 과정에서 발생한 행동과 피드백이 일회성으로 끝나 조직의 개선 데이터로 축적되지 않는다.

## 3. 서비스 목표

IX Value Loop의 목표는 핵심가치를 설명하는 것이 아니라, 신규 입사자가 핵심가치를 실제 업무의 판단 기준으로 사용할 수 있도록 만드는 것이다.

본 서비스에서는 핵심가치의 내재화를 다음과 같이 정의한다.

> 새로운 업무 상황에서도 핵심가치를 자신의 직무에 맞게 해석하고, 이를 행동과 의사결정에 적용하며, 그 근거를 설명할 수 있는 상태

이를 위해 다음의 순환 구조를 만든다.

```text
가치 이해 → 직무별 행동으로 변환 → 실제 업무에서 실행 → 근거 축적 → 팀장 피드백 → 다음 업무에 재적용
```

## 4. 핵심 서비스 콘셉트 및 가설과 MVP 검증 범위

IX Value Loop는 12주 동안 매주 하나의 핵심가치를 실제 업무와 연결하는 온보딩 포털이다.

인사팀은 12개 핵심가치의 주차별 순서를 사전에 설정한다. 이후 신규 입사자의 입사일을 기준으로 해당 주차의 핵심가치가 자동으로 활성화된다.

팀장은 기존처럼 신규 입사자에게 실제 업무를 배정한다. 배정된 업무는 신규 입사자의 계정에 바로 전달되며, 시스템은 해당 주차의 핵심가치·직무·업무 유형에 적합한 Value Action을 조회해 업무와 함께 제공한다.

신규 입사자는 별도의 가상 미션을 수행하는 대신, 실제 업무를 진행하면서 Value Action을 투두리스트처럼 확인하고 실천한다. 업무 과정에서 생성된 기존 산출물을 행동 근거로 등록하면 AI가 이를 정리해 Evidence Card와 가치별 누적 리포트를 생성한다.

### 4.1 핵심 가설

신규 입사자에게 실제 업무와 연결된 Value Action을 제시하고, 행동 근거와 팀장 피드백을 Evidence Card로 축적하면, 신규 입사자는 인터엑스의 핵심가치를 실제 업무의 행동 기준으로 이해하고 적용할 수 있을 것이다.

기능별로 가설을 세 개씩 나누지 않고, 전체 서비스에 대한 가설 하나만 둔다.

IX Value Loop는 다음 흐름을 통해 가설을 구현한다.

```text
Value Action으로 행동 안내 → 실제 업무에서 실행 → 행동 근거 등록 → AI Evidence Card 생성 → 팀장 피드백 → 다음 업무에 재적용
```

Evidence Card는 신규 입사자가 핵심가치를 얼마나 잘 암기했는지를 평가하지 않는다. 실제 업무에서 어떤 행동을 했고, 판단이 어떻게 변화했으며, 팀장이 이를 어떻게 관찰했는지를 근거 중심으로 보여준다.

초기에는 한 주의 행동 근거를 기록하고, 12주 동안 카드가 누적되면서 신규 입사자가 핵심가치를 새로운 업무에서도 스스로 적용하는 과정을 보여준다.

### 4.2 MVP에서 검증할 범위

12주간의 가치 내재화는 단기간의 MVP 테스트만으로 직접 검증하기 어렵다. 따라서 MVP 단계에서는 다음 세 가지 사용성을 우선 검증한다.

- 신규 입사자가 핵심가치와 실제 업무, Value Action의 관계를 이해하는가
- 실제 업무 흐름을 방해받지 않고 행동 근거와 Evidence Card를 만들 수 있는가
- 팀장이 Evidence Card를 바탕으로 짧은 시간 안에 근거 중심 피드백을 제공할 수 있는가

즉, MVP에서는 내재화의 최종 효과를 증명하기보다, 내재화로 이어지는 행동 구조가 사용 가능한지를 검증한다.

### 4.3 MVP 사용성 테스트 계획

#### 테스트 대상

- 신규 입사자 역할 참가자 5명
- 팀장 역할 참가자 2명
- 직장 또는 팀 프로젝트 경험이 있는 참가자를 우선 선정한다.

테스트는 화면을 설명하지 않고 과제를 제시한 뒤, 참가자가 직접 수행하는 방식으로 진행한다. 진행 중에는 생각하는 내용을 말하게 하는 Think-aloud 방식과 종료 후 인터뷰를 함께 사용한다.

#### 테스트 1. 가치와 행동의 관계 이해

상황:

참가자에게 신규 입사자 주간 대시보드를 보여준다.

화면에는 다음 정보가 표시되어 있다.

- 이번 주 핵심가치: 강박적 호기심
- 실제 업무: 반복적인 HR 문의 분석 및 자동화 프로토타입 구축
- Value Action 투두리스트

수행 과제:

- 이번 주 핵심가치를 찾는다.
- 자신에게 배정된 실제 업무를 확인한다.
- 업무에서 수행해야 할 행동을 설명한다.

확인 항목:

정량:

- 도움 없이 과제를 완료한 참가자 비율
- 핵심가치와 Value Action을 찾는 데 걸린 시간
- 잘못 이해하거나 다시 확인한 횟수

정성:

- 핵심가치와 실제 업무가 자연스럽게 연결되어 보이는가?
- Value Action을 보고 구체적으로 무엇을 해야 하는지 알 수 있는가?
- 어려운 용어나 의미가 불분명한 표현은 무엇인가?

성공 기준:

- 참가자 5명 중 4명 이상이 별도의 설명 없이 핵심가치와 수행 행동을 찾는다.
- 참가자가 Value Action을 그대로 읽는 것에 그치지 않고, 실제 업무에서 무엇을 해야 하는지 자신의 말로 설명한다.

#### 테스트 2. 행동 근거 등록 및 Evidence Card 생성

상황:

참가자가 Value Action을 수행했다고 가정하고 다음 자료를 제공한다.

- 구현 전 문제 가설
- 사용자 인터뷰 기록
- 인터뷰 후 변경된 판단
- 수정된 프로토타입 링크

수행 과제:

- 완료한 Value Action을 선택한다.
- 행동과 판단 변화를 작성한다.
- 기존 업무 산출물을 행동 근거로 등록한다.
- AI Evidence Card를 생성하고 내용을 확인한다.
- 필요한 내용을 수정한 뒤 Card를 확정한다.

확인 항목:

정량:

- 도움 없이 전체 과정을 완료한 참가자 비율
- 행동 근거 등록부터 Card 확정까지 걸린 시간
- 입력 과정에서 발생한 오류와 중단 횟수
- AI가 생성한 내용 중 수정이 필요했던 항목 수

정성:

- 별도의 보고서를 새로 작성하는 느낌이 드는가?
- 어떤 자료를 행동 근거로 등록해야 하는지 알 수 있는가?
- Evidence Card가 자신의 실제 행동을 정확하게 보여주는가?
- Card를 통해 행동과 핵심가치의 관계가 더 명확해졌는가?
- AI가 과장하거나 근거 없이 작성한 내용은 없는가?

성공 기준:

- 참가자 5명 중 4명 이상이 도움 없이 Card를 확정한다.
- 참가자가 기존 업무 산출물을 행동 근거로 활용한다.
- Card에 원본 근거에 없는 행동이나 성과가 포함되지 않는다.
- 사용자가 “별도의 추가 보고 업무”라고 느끼는 지점이 발견되면 입력 단계를 축소한다.

#### 테스트 3. 팀장 피드백

상황:

팀장 역할 참가자에게 신규 입사자가 확정한 Evidence Card와 원본 근거를 보여준다.

수행 과제:

- 신규 입사자가 어떤 행동을 했는지 확인한다.
- 해당 행동이 핵심가치와 연결되는지 판단한다.
- 잘 적용한 부분과 다음 업무에서 강화할 행동을 작성한다.
- 누적 리포트 반영을 승인한다.

확인 항목:

정량:

- Card를 이해하고 피드백을 작성하는 데 걸린 시간
- 원본 근거를 추가로 확인한 횟수
- 피드백을 작성하기 위해 추가 정보가 필요했던 항목 수

정성:

- Evidence Card만으로 신규 입사자의 행동과 판단 변화를 이해할 수 있는가?
- 핵심가치와 행동의 연결 근거가 충분한가?
- 어떤 정보가 부족하거나 불필요한가?
- 실제 업무 중에도 부담 없이 피드백할 수 있는가?
- 다음 행동을 구체적으로 제안할 수 있는가?

성공 기준:

- 팀장이 3분 이내에 행동과 판단 변화를 이해하고 피드백을 작성한다.
- 별도의 장문 보고서나 추가 면담 없이 다음 행동을 제안할 수 있다.
- 팀장이 판단에 사용한 근거를 Card에서 직접 확인할 수 있다.

## 5. 기획 원칙

### 5.1 실제 업무가 곧 온보딩 미션이다

별도의 가상 과제를 부여하지 않는다. 팀장이 배정한 실제 업무를 중심으로 온보딩을 진행한다.

### 5.2 핵심가치는 같지만 행동은 직무별로 다르다

가치의 정의는 전사적으로 동일하게 유지하되, 구체적인 실천 행동은 직무와 업무 유형에 맞게 제공한다.

### 5.3 처음에는 안내하고, 점차 스스로 판단하게 한다

입사 초기에는 구체적인 행동을 제시하고, 후반으로 갈수록 입사자가 직접 Value Action을 설계하도록 자유도를 높인다.

### 5.4 추가 보고 업무를 최소화한다

인터뷰 기록, 분석 문서, 회의록, 프로토타입 링크 등 실제 업무에서 이미 만들어진 산출물을 행동 근거로 활용한다.

### 5.5 AI는 사람을 평가하지 않고 근거를 정리한다

AI가 문화 적합도나 사람의 성향을 점수화하지 않는다. 등록된 근거와 팀장 피드백을 바탕으로 행동과 변화 과정을 구조화한다.

## 6. 사용자 구성

### 6.1 신규 입사자

- 이번 주 핵심가치와 실제 업무를 확인한다.
- Value Action을 업무 투두리스트처럼 실천한다.
- 실행 결과와 업무 산출물을 행동 근거로 등록한다.
- AI가 생성한 Evidence Card를 확인하고 수정한다.
- 팀장 피드백과 자신의 가치별 성장 기록을 확인한다.

### 6.2 팀장

- 신규 입사자에게 실제 업무를 배정한다.
- 시스템이 추천한 Value Action을 확인하거나 필요한 경우 수정한다.
- 신규 입사자가 제출한 행동 근거와 Evidence Card를 검토한다.
- 짧은 관찰 피드백과 다음 업무에서의 실천 방향을 남긴다.

### 6.3 인사팀

- 12주 핵심가치 커리큘럼을 사전에 관리한다.
- 가치·직무·업무 유형별 Value Action Library를 관리한다.
- 개인을 평가하기보다 익명화된 온보딩 운영 데이터를 확인한다.
- 적용하기 어려운 가치와 효과가 낮은 Action을 찾아 다음 온보딩 과정에 반영한다.

## 7. 12주 핵심가치 커리큘럼

12개 핵심가치는 입사 초기 적응에서 자율적인 도전으로 이어지도록 순서를 구성한다.

### 1단계: 조직과 관계 형성

- 1주차 — 관계기반 전략소통
- 2주차 — 강박적 호기심
- 3주차 — 성장지향 피드백

입사 초기에는 동료와 관계를 형성하고, 질문하고, 피드백을 주고받는 행동을 먼저 익힌다.

### 2단계: 문제와 목표 정의

- 4주차 — 가치중심적 문제해결
- 5주차 — 근본적 비판 사고
- 6주차 — 선도적/정량 목표의식

업무의 본질을 파악하고, 기존 방식을 검토하며, 측정 가능한 목표를 설정한다.

### 3단계: 실행과 프로세스 개선

- 7주차 — 초효율적 시간관리
- 8주차 — 혁신 프로세스 가속화
- 9주차 — 집요한 끈기

업무를 효율적으로 실행하고, AI와 새로운 기술로 프로세스를 개선하며, 실패 이후에도 해결을 이어간다.

### 4단계: 성과와 자율성 확장

- 10주차 — 최고수준의 결과지향
- 11주차 — 자발적 성장동기
- 12주차 — 미래낙관적 도전

결과물의 완성도를 높이고, 스스로 성장 방향을 찾으며, 불확실한 상황에서도 새로운 도전을 이어간다.

주차별 핵심가치는 인사팀이 매주 새로 지정하지 않는다. 12주 커리큘럼을 사전에 등록하고, 신규 입사자의 온보딩 주차에 따라 자동 적용한다.

## 8. Value Action Library

Value Action은 핵심가치를 실제 업무에서 실천할 수 있도록 만든 구체적인 행동 단위다.

AI가 매번 새로운 Action을 생성하지 않고, 사전에 검증된 Value Action Library에서 조건에 맞는 행동을 조회한다.

Value Action 구성 기준:

- 핵심가치
- 직무
- 업무 유형
- 온보딩 단계
- 행동 내용
- 권장 행동 근거
- 완료 기준

업무 유형은 다음과 같이 분류할 수 있다.

- 사용자 및 현업 인터뷰
- 업무 프로세스 분석
- 문제 정의
- 데이터 분석
- 기능 및 서비스 기획
- 프로토타입 구축
- 사용자 검증
- 협업 및 커뮤니케이션
- 결과물 개선

Value Action 예시:

- 핵심가치: 강박적 호기심
- 직무: AX
- 실제 업무: 반복적인 HR 문의를 분석하고 자동화 프로토타입 구축

Value Action:

- 구현 전에 문제의 근본 원인에 대한 가설을 한 문장으로 작성한다.
- 실제 사용자 또는 업무 담당자 2명 이상에게 현재 업무 흐름을 확인한다.
- 처음 가설과 조사 후 판단이 어떻게 달라졌는지 기록한다.

행동 근거:

- 사용자 인터뷰 기록
- As-Is 업무 흐름도
- 변경된 기능 정의서
- 프로토타입 링크

이 구조를 사용하면 동일한 가치를 유지하면서도 각 직무와 업무 상황에 적합한 행동을 제공할 수 있다.

## 9. 점진적 자율성 설계

### 1~4주차: 가이드형

시스템이 2~3개의 필수 Value Action과 행동 근거의 예시를 제공한다. 신규 입사자는 안내된 행동을 실제 업무에서 수행한다.

### 5~8주차: 선택·수정형

시스템이 3~5개의 Value Action을 제안한다. 신규 입사자는 자신의 업무에 적합한 Action을 선택하거나 일부 내용을 수정할 수 있다.

### 9~12주차: 자율 설계형

신규 입사자가 핵심가치를 바탕으로 직접 Value Action, 완료 기준, 행동 근거를 작성한다. AI는 공식 가치 정의와의 부합 여부를 검토하고, 팀장이 최종 확인한다.

이를 통해 초기에는 회사가 기대하는 행동을 명확히 알려주고, 후반에는 신규 입사자가 새로운 업무에서도 스스로 가치를 적용하도록 만든다.

## 10. 주간 온보딩 프로세스

### 업무 시작

팀장이 신규 입사자에게 실제 업무를 배정한다. 배정된 업무는 신규 입사자 계정에 바로 표시된다.

시스템은 현재 주차의 핵심가치와 신규 입사자의 직무, 업무 유형, 온보딩 단계를 기준으로 Value Action Library를 조회한다.

### 업무 수행

신규 입사자의 대시보드에는 다음 정보가 함께 표시된다.

- 이번 주 핵심가치
- 팀장이 배정한 실제 업무
- 해당 업무에 적용할 Value Action
- 권장 행동 근거
- Action별 진행 상태

신규 입사자는 업무를 수행하면서 Action을 계속 인지하고, 완료한 항목을 체크한다.

### 행동 근거 등록

업무가 끝난 후 별도의 긴 보고서를 작성하는 대신 실제 업무에서 만들어진 산출물을 등록한다.

- 어떤 행동을 했는가
- 그 행동으로 무엇을 발견했는가
- 처음의 생각이나 판단이 어떻게 달라졌는가
- 업무 결과에 어떤 영향을 주었는가
- 이를 보여주는 산출물은 무엇인가

### Evidence Card 생성

AI는 등록된 행동과 산출물을 기반으로 Evidence Card를 작성한다.

Evidence Card에는 다음 내용이 포함된다.

- 적용한 핵심가치
- 수행한 Value Action
- 행동 근거
- 업무 중 발견한 내용
- 판단 또는 접근 방식의 변화
- 업무 결과에 미친 영향
- 다음 업무에서 이어갈 행동

AI가 생성한 내용은 신규 입사자가 수정할 수 있으며, 모든 요약 내용은 원본 근거와 연결된다.

### 팀장 피드백

팀장은 Evidence Card를 확인하고 짧은 피드백을 남긴다.

- 실제로 관찰된 행동
- 업무 결과에 미친 영향
- 잘 적용된 부분
- 다음 업무에서 강화할 행동

팀장 피드백은 가치별 누적 리포트에 함께 반영된다.

## 11. AI 활용 범위

### AI를 사용하지 않는 영역

- 주차별 핵심가치 결정
- Action 완료 여부 계산
- 행동 근거 개수 집계
- 진행률 계산
- 문화 적합도 점수화
- 신규 입사자 자동 평가

해당 영역은 사전 설정과 일반적인 시스템 로직으로 처리한다.

### AI를 사용하는 영역

- 업무 유형이 불명확한 경우 적합한 유형 분류
- Library 내 Value Action 추천
- 후반부 사용자가 작성한 Action과 핵심가치의 부합 여부 검토
- 행동 근거와 판단 변화 요약
- Evidence Card 생성
- 여러 주차의 기록을 연결한 가치별 성장 리포트 생성

즉, AI는 핵심가치를 임의로 해석하거나 사람을 평가하는 역할이 아니라, 분산된 업무 근거를 읽고 의미 있는 성장 기록으로 연결하는 역할을 한다.

## 12. 가치별 누적 리포트

주간 기록은 일회성으로 끝나지 않고 가치별 리포트에 누적된다.

### 신규 입사자 리포트

- 12개 핵심가치별 실천 현황
- 가치별 업무 사례
- 등록한 행동 근거
- 팀장 피드백
- 업무 판단이 변화한 과정
- 앞으로 이어갈 개인 행동 원칙

### 팀장 리포트

- 신규 입사자가 실제로 보여준 가치별 행동
- 아직 근거가 부족한 가치
- 다음 업무에서 제공할 성장 기회
- 30일·90일 단위 성장 변화

### 인사팀 리포트

- 가치별 Action 수행 현황
- 직무별로 적용하기 어려운 핵심가치
- 완료율 또는 활용도가 낮은 Action
- 반복적으로 발생하는 온보딩 장애 요인
- 다음 기수의 커리큘럼과 Action 개선 방향

인사팀 리포트는 개인의 문화 적합도를 평가하는 용도가 아니라, 온보딩 프로그램 자체를 개선하기 위한 익명화된 데이터로 활용한다.

## 13. 핵심 사용자 화면

### 신규 입사자 주간 대시보드

- 현재 온보딩 주차
- 이번 주 핵심가치
- 핵심가치의 간단한 설명
- 팀장이 배정한 실제 업무
- Value Action 투두리스트
- 행동 근거 등록 버튼
- 이번 주 진행 상태

### 행동 근거 등록 화면

- 완료한 Value Action
- 실제로 수행한 행동
- 업무 중 발견한 내용
- 변경된 판단
- 업무 결과에 미친 영향
- 파일 또는 링크 첨부

### AI Evidence Card

- 핵심가치와 업무의 연결
- 핵심 행동
- 근거 자료
- 판단 변화
- 업무 영향
- 다음 실천 제안
- 사용자 수정 및 확정

### 팀장 피드백 화면

- 신규 입사자의 Evidence Card
- 원본 근거 확인
- AI 요약 수정
- 관찰 피드백 입력
- 다음 행동 제안
- 승인 및 리포트 반영

### 가치별 누적 리포트

- 12개 핵심가치 진행 현황
- 가치별 Evidence Card
- 팀장 피드백
- 반복적으로 나타난 행동
- 이전 가치가 다른 업무에서 다시 적용된 사례

## 14. MVP 구현 범위

프로토타입에서는 12주 전체 기능을 얕게 구현하기보다 한 주의 온보딩 루프를 완결성 있게 보여준다.

핵심 구현 범위:

- 신규 입사자 주간 대시보드
- 실제 업무와 핵심가치 표시
- Value Action 투두리스트
- 행동 근거 등록
- AI Evidence Card 생성
- 팀장 피드백 입력
- 가치별 누적 리포트 반영

팀장의 업무 배정 기능과 Value Action 자동 매칭 구조도 서비스에는 포함하되, 1분 시연영상에서는 사전에 설정된 상태로 시작한다.

## 15. 1분 시연영상 구성

### 0~10초: 이번 주 업무 확인

신규 입사자 계정으로 시작한다.

화면에는 다음 정보가 이미 표시되어 있다.

- 이번 주 핵심가치
- 팀장이 배정한 실제 업무
- Value Action 투두리스트

업무를 배정하고 Action을 매칭하는 과정은 영상에서 직접 보여주지 않는다.

### 10~25초: Value Action 완료 및 근거 등록

신규 입사자가 마지막 Action을 완료하고, 업무 중 발견한 내용과 판단 변화를 작성한다. 인터뷰 기록이나 프로토타입 링크를 행동 근거로 첨부한다.

### 25~38초: AI Evidence Card 생성

AI가 등록된 근거를 읽고 다음 내용을 정리한다.

- 어떤 가치를 적용했는가
- 어떤 행동을 했는가
- 무엇을 발견했는가
- 판단이 어떻게 달라졌는가
- 업무 결과에 어떤 영향을 주었는가

### 38~48초: 팀장 피드백

미리 열어둔 팀장 화면으로 전환한다. 팀장이 Evidence Card를 확인하고 한 줄 피드백과 다음 행동을 남긴다.

### 48~58초: 누적 리포트 반영

신규 입사자의 가치별 누적 리포트에 Evidence Card와 팀장 피드백이 반영되는 모습을 보여준다.

### 58~60초: 핵심 메시지

> 핵심가치를 배우는 온보딩에서, 실제 업무로 증명하고 축적하는 온보딩으로.

PPT에서는 영상에서 생략한 백그라운드 구조를 다음 한 문장으로 설명한다.

> 사전에 설정된 12주 핵심가치와 팀장이 배정한 실제 업무를 기준으로, 시스템이 직무·업무 유형에 맞는 검증된 Value Action을 대상자에게 제공한다.

## 16. 차별점

### 교육 콘텐츠가 아니라 업무 행동을 설계한다

핵심가치를 읽고 퀴즈를 푸는 방식이 아니라, 실제 업무에서 어떤 행동을 해야 하는지 구체적으로 안내한다.

### 동일한 가치를 직무별로 다르게 적용한다

가치의 의미는 유지하면서 AX, PM, 전략, 마케팅, HR 등 직무별 실천 행동을 다르게 제공한다.

### AI 생성 중심이 아닌 검증된 Action Library를 사용한다

AI가 매번 행동을 새로 생성하지 않기 때문에 토큰 사용량을 줄이고, 가치 해석의 일관성과 데이터 비교 가능성을 확보한다.

### 온보딩과 업무를 분리하지 않는다

실제 업무와 기존 산출물을 그대로 활용해 신규 입사자와 팀장의 추가 부담을 최소화한다.

### 개인 기록이 조직의 개선 데이터로 이어진다

개인의 행동 근거가 누적되면서 어떤 가치와 Action이 실제 현업에서 효과적인지 확인하고, 다음 온보딩 과정을 개선할 수 있다.

## 17. 기대 효과

### 신규 입사자

- 추상적인 핵심가치를 실제 행동으로 이해할 수 있다.
- 업무 중 무엇을 의식해야 하는지 명확하게 알 수 있다.
- 자신의 판단과 성장 과정을 구체적인 근거로 확인할 수 있다.

### 팀장

- 별도의 온보딩 과제를 만들지 않고 실제 업무를 통해 코칭할 수 있다.
- 신규 입사자의 행동과 판단 과정을 근거 중심으로 확인할 수 있다.
- 짧은 피드백으로 다음 업무의 성장 방향을 제시할 수 있다.

### 인사팀

- 온보딩 참여율뿐 아니라 핵심가치가 실제 업무에 적용된 과정을 확인할 수 있다.
- 직무별로 효과적인 Value Action을 데이터로 축적할 수 있다.
- 온보딩 프로그램을 기수별로 지속해서 개선할 수 있다.

## 18. 핵심 제안 문장

IX Value Loop는 신규 입사자가 인터엑스의 12가지 핵심가치를 실제 업무 속 행동으로 실천하고, 그 근거와 피드백을 축적해 스스로 다음 행동을 설계하도록 돕는 AI 기반 온보딩 포털이다.

이 기획에서 가장 중요한 장면은 AI가 뭔가를 화려하게 생성하는 순간이 아니라, 신규 입사자의 실제 업무가 가치 → 행동 → 근거 → 피드백 → 성장 기록으로 연결되는 순간이다. 이 점이 일반적인 AI 온보딩 챗봇이나 교육형 포털과 가장 분명하게 구별되는 부분이다.
